# Obrazek

Po zeskanowaniu kodu QR otwiera się strona z losowym obrazkiem z folderu `obrazki`. Przycisk „Losuj kolejny” pokazuje inny.

Strona: https://adrek-lab.github.io/obrazek/

![Kod QR](kod-qr.png)

## Jak dodać obrazek

1. Wrzuć plik do folderu `obrazki` (np. `3.jpg`).
2. W pliku `index.html` dopisz go do listy `OBRAZKI`, np. `'obrazki/3.jpg',`.

## Ciasteczko z wróżbą

Przycisk „Ciasteczko z wróżbą” pokazuje losową śmieszną rozmowę w stylu IRC. Cytaty są w pliku `cytaty.js` – żeby dodać nowy, skopiuj jeden blok `[ ... ],` i zmień tekst.
